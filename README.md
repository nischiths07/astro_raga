# AstroRaga | Royal Vedic AI Sanctuary

AstroRaga is a premium, AI-powered Vedic Astrology application built with Next.js and Framer Motion. It provides deep, personalized cosmic insights through a "Royal" interactive experience.

## ✨ Features

- **Royal Vedic Persona (AstroSage)**: A master AI agent specialized in Vedic Shastras, Karma analysis, and Life Purpose (Atma Dharma).
- **Premium Design**: A high-end, mobile-optimized "Royal" aesthetic featuring:
  - Gold metallic gradients
  - Elegant Cinzel typography
  - Glassmorphism UI components
- **Interactive AI Chat**: Real-time conversational astrology with a mystical, responsive interface.
- **Deep-Dive Predictions**: 
  - Cosmic Blueprint (Present)
  - Atma Dharma (Soul Purpose)
  - Past Karma Echoes
  - Future Trajectory
  - Divine Spiritual Remedies
- **Multi-Lingual**: Support for English and Kannada.
- **Robust API System**: Intelligent multi-model fallback to ensure high availability.

## 🚀 Tech Stack

- **Framework**: Next.js (App Router)
- **Styling**: CSS Modules & Global Vanilla CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **AI Integration**: OpenRouter (Unified API for Gemini, Llama, and Mistral)

## 🛠️ Setup & Installation

1. **Clone the repository**:
   ```bash
   git clone <your-repo-url>
   cd astroraga
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Create a `.env.local` file in the root directory and add your API keys:
   ```env
   OPENROUTER_API_KEY=your_key_here
   GEMINI_API_KEY=your_key_here
   ```

4. **Run the development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📖 Project Structure

- `src/app/`: Next.js pages and API routes.
- `src/components/`: Reusable UI components (BottomNav, LanguageToggle, etc.).
- `src/lib/`: Shared utilities and translation strings.
- `public/`: Static assets.
